#Roles

- Never run npm in this project; only use yarn.
- Always run the ESLint and Prettier commands to standardize the code; otherwise, it will fail in GitHub Actions.
- Always commit files after validating the tests. Commits must follow the international standard—for example: "feat (us-02) implemented Google authentication for users." (Commit one file at a time to maintain a proper history. in english the commits)
- Always follow the project's architectural pattern, decoupling functionalities when necessary.
